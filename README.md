# 忍者からくり屋敷

PowerPoint素材を用いた、数字の変化から規則を見つけるWebゲームです。

## GitHub Pagesで公開

1. `ninja-karakuri` の名前で新しい公開リポジトリを作ります。
2. このフォルダの **中身をすべて** リポジトリのルートにアップロードします（`index.html` が一番上にある状態）。
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save。
4. 公開URLをiPhoneのSafariで開き、共有メニューから「ホーム画面に追加」。

`apple-touch-icon.png` は角丸加工していない正方形で、iPhoneが表示時に角を丸くします。
